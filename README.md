## ✨ Features

- **📱 Complete Responsive Layout**: Optimized across all viewport sizes — from ultra-compact smartphones (320px) and tablets up to widescreen 4K displays.
- **🎨 Dark Terminal Aesthetic**: Custom-styled syntax-highlighted code terminal, glowing ambient fields, and subtle backdrop grid.
- **⚡ Zero Framework Overhead**: Built using lightweight, pure semantic HTML5, Vanilla CSS3, and Vanilla JavaScript (ES6+) for instant page loads.
- **🍔 Accessible Mobile Navigation**: Responsive hamburger toggle with a blurred drawer overlay, keyboard navigation (`ESC` to exit), and body scroll locking.
- **💬 Direct WhatsApp Integration**: Prominent, glowing circular WhatsApp floating action button connecting visitors directly to chat via WhatsApp (`0318-8761416`).
- **👀 Scroll-Spy & Reveal Animations**: Smooth section observation with active navigation link highlighting and staggered entrance animations using the native `IntersectionObserver` API.
- **🔝 Floating Back-to-Top Action**: Automatically appears on scroll for quick one-tap navigation.

## 🚀 Getting Started

Since this project uses vanilla web standards, no build tools or package managers are required.

### 1. Clone the repository
```bash
git clone https://github.com/mubashirtariq650/portfolio.git
cd portfolio
```

### 2. View in Browser
Simply double-click `index.html` or open it with any web browser:
```bash
# Windows
start index.html

# Mac
open index.html

# Linux
xdg-open index.html
```

Or run any local static file server:
```bash
# Using Python
python -m http.server 8000

# Using Node / npx
npx serve .
```
Then visit `http://localhost:8000` in your browser.
